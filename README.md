# LUFS Audio Catalog Website

A static Astro/Svelte website for browsing and streaming LUFS Audio releases. Features a persistent audio player, proof-of-work reports embedded from workchain output, and local development without external cloud services.

**Target URL:** catalog.lufs.audio

---

## Quick Start

```bash
# Install dependencies
npm install

# Run local development (with optional ingest)
./catalog-dev.sh --ingest   # ingest from workchain + start dev server
npm run dev                 # start dev server only (assets must already exist)
```

---

## Project Overview

- **Framework:** Astro v5 (`output: 'static'`)
- **UI Components:** Svelte 5 (player bar, state management via nanostores)
- **Audio Engine:** Howler.js v2 (HTML5 streaming mode)
- **Content:** Markdown files in `src/content/releases/` with YAML frontmatter
- **Styling:** CSS custom properties with dark theme (LUFS brand)

## Ingest Workflow

The ingest script reads from a workchain output directory and generates the site content:

### Input (CATALOG_SOURCE_PATH)

```
[source-dir]/
└── [collection-id]/           # e.g., a98ff_praise-legend-road
    ├── artwork/
    │   └── YYYY-MM-DD_artwork.png
    ├── [track-number]/
    │   ├── [filename]_final/
    │   │   ├── [filename]_final_report.html
    │   │   └── artwork/
    │   ├── [filename].mp3
    │   └── [filename].render_stats.html
```

### Output

- **Content:** `src/content/releases/[slug].md` — metadata + track list
- **Audio:** `public/audio/[collectionId]/[n]/[filename].mp3`
- **Reports:** `public/reports/[collectionId]/[n]/final_report.html` (sanitized)
- **Artwork:** `public/covers/[collectionId]/[n]/[artwork files]`

### Running Ingest

```bash
# Set source path (or use default: /Volumes/project/continuo/catalogs)
export CATALOG_SOURCE_PATH=/path/to/your/catalogs

# Run ingest
pnpm catalog:ingest:local
```

The script will:
1. Walk the source directory
2. Parse `_final_report.html` for catalog number, SHA256, saturation
3. Copy MP3, artwork, and reports to `public/`
4. Create/update `.md` file with track metadata

## Expected I/O

### Input (per release)

| Field | Source | Example |
|-------|--------|---------|
| `collectionId` | Directory name | `a98ff_praise-legend-road` |
| `title` | User input | `"Continuo"` |
| `project` | User input | `"Continuo"` |
| `releaseDate` | User input | `2024-10-01` |
| `isrc` | User input | `USXXXXXXXX2401` |
| `tracks` | Parsed from workchain | Array of track objects |

### Output (per track)

| Field | Path | Example |
|-------|------|---------|
| `audioPath` | `public/audio/[id]/[n]/[file].mp3` | `/audio/a98ff_praise-legend-road/1/track.mp3` |
| `finalReport` | `public/reports/[id]/[n]/final_report.html` | `/reports/a98ff_praise-legend-road/1/final_report.html` |
| `renderStatsPath` | `public/reports/[id]/[n]/render_stats.html` | `/reports/a98ff_praise-legend-road/1/render_stats.html` |
| `artwork.main` | `public/covers/[id]/[n]/artwork.png` | `/covers/a98ff_praise-legend-road/1/artwork.png` |

## Environment Variables

Create `.env.local` for local development:

```bash
# Source path for workchain catalogs (required for ingest)
CATALOG_SOURCE_PATH=/Volumes/project/continuo/catalogs

# Optional: show draft/unreleased items
PUBLIC_SHOW_DRAFTS=false
```

## Production Deployment

For production on Hostinger with Cloudflare R2:

1. **Set up R2** with bucket `lufs-audio`
2. **Deploy Worker** for signed audio URLs
3. **Run ingest** with R2 upload (not implemented in local script)
4. **Build & deploy:**
   ```bash
   npm run build
   # Push dist/ to hostinger branch for auto-deploy
   ```

See `docs/PRD.md` and `docs/TDD.md` for full production architecture.

## Testing

Since this is an Astro/Svelte project:

4. Navigate to release detail pages to verify workchain reports
